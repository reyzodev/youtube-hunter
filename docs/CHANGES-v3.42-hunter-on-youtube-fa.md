1. **Niche Scan:** دکمه «Send winners to AI Ideas» حذف شد (`InsightsPage.qml`).
2. **دکمه ✦ «Send to AI Ideas» روی کارت‌ها درست شد.** قبلاً ویدیو در جدول قدیمی `ideas` نوشته می‌شد که صفحه AI Ideas اصلاً آن را نمی‌خواند. حالا ویدیو مستقیم در AI Ideas به‌عنوان مرجع تیک می‌خورد (`IdeasVM.addReferences`) و آیکون روی کارت روشن می‌ماند.

4. **Hunter روی یوتیوب (افزونه مرورگر + پل محلی):**
   - `browser-extension/`: افزونه کروم/اج (MV3). کنار Like/Share یک دکمه «Hunter» با لوگوی برنامه + فلش دانلود اضافه می‌کند (در Shorts هم هست).
   - کلیک → پنل گوشه بالا-راست صفحه یوتیوب: کیفیت‌های واقعی ویدیو با حجم (نردبان حجم)، انتخاب کیفیت، دکمه دانلود. همان ردیف انتخاب‌شده به نوار پیشرفت تبدیل می‌شود.
   - دانلود را خود برنامه انجام می‌دهد (همان مسیر صفحه Downloads)، پنجره برنامه لازم نیست باز شود. پایان کار → اعلان دسکتاپ + «نمایش در پوشه».
   - اگر برنامه باز نباشد: دکمه «اجرای یوتیوب هانتر» از طریق لینک `youtubehunter://` (نصب‌کننده ثبتش می‌کند) برنامه را **کوچک‌شده** اجرا می‌کند؛ اگر از قبل باز باشد نسخه دوم باز نمی‌شود.
   - `app/qml_backend/web_bridge.py`: سرور JSON روی `127.0.0.1:47391`. فقط درخواست افزونه‌ها (Origin از نوع extension + هدر `X-YTH-Bridge`) پذیرفته می‌شود؛ هیچ سایتی نمی‌تواند دانلود شروع کند. خاموش کردن: `"browser_bridge": false` در کانفیگ.

## نصب افزونه
کروم/اج → `chrome://extensions` → Developer mode → Load unpacked → پوشه `browser-extension` (در پوشه نصب برنامه هم کپی می‌شود).
