# تغییرات بخش دانلود

## ۱. دانلود دقیق با کیفیت انتخابی
- باگ ویدیوهای عمودی (Shorts) رفع شد: قبلاً فیلتر `height<=N` روی ویدیوی عمودی یک استریم کوچک‌تر (مثلاً 608x1080) را برمی‌داشت، چک کیفیت رد می‌شد و دانلود کلاً شکست می‌خورد. حالا محدودیت کیفیت همیشه روی ضلع کوتاه اعمال می‌شود (`aspect_ratio`).
- مسیر فایل نهایی بعد از merge/تبدیل دقیق پیدا می‌شود؛ اگر فایل روی دیسک نباشد، دانلود موفق گزارش نمی‌شود و روش بعدی امتحان می‌شود.
- `import json` جاافتاده و کد مرده‌ی بالای `download.py` اصلاح شد.

## ۲. انتخاب فرمت هنگام دانلود
- در پنجره‌ی انتخاب کیفیت یک بخش «فرمت ویدیو / فرمت صدا» اضافه شد.
- ویدیو: MP4 / MKV / WEBM — صدا: MP3 / M4A / OPUS / WAV / FLAC
- انتخاب در تنظیمات برنامه ذخیره می‌شود (`dl_video_container`, `dl_audio_codec`).
- فرمت همراه کیفیت ذخیره می‌شود (`1080p@mkv`) تا ادامه‌ی دانلود متوقف‌شده با همان فرمت انجام شود.
- برای MP4 صدای AAC ترجیح داده می‌شود (سازگاری بیشتر). برای WEBM اگر استریم VP9 در آن کیفیت نباشد، خودکار تبدیل می‌شود.

فایل‌های تغییرکرده: `app/core/download.py`, `app/qml_backend/vm/quality_probe.py`, `downloads_vm.py`, `archive_vm.py`, `niche_vm.py`, `app/qml/components/QualityPicker.qml`, `app/locales/fa.py`
