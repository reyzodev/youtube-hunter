# v3.28 — تغییرات
1. **هشدار IP ایران (و کشورهایی که یوتیوب فیلتر است)** — `app/core/geo.py` + `vm/geo_vm.py` + `components/GeoGateDialog.qml`. ۱.۸ ثانیه بعد از باز شدن برنامه کشور IP بررسی می‌شود (چند سرویس هم‌زمان، از همان مسیر پراکسی‌ای که برنامه واقعاً استفاده می‌کند). اگر ایران بود پاپ‌آپ با انیمیشن «مسیر» نشان داده می‌شود: «فعلاً رد شو» / «تنظیمات پراکسی» / «بررسی دوباره». اگر سرویس‌ها در دسترس نبودند هیچ‌چیز بلاک نمی‌شود.
2. **دروازه اسکرپر** — قبل از هر اسکرپ مسیر API یوتیوب بررسی می‌شود (httplib2 فقط پراکسی محیطی را می‌خواند، نه System proxy و نه پراکسی تنظیمات). با IP ایران اسکرپ متوقف و هشدار داده می‌شود: «لغو» / «در هر صورت اسکرپ کن» / «بررسی دوباره» (اگر بعد از روشن کردن VPN پاک بود، اسکرپ خودکار شروع می‌شود). لیست کشورها: `RESTRICTED_COUNTRIES` در geo.py.
3. **AI Chat** — پرامپت سیستم بازنویسی شد (جواب اول، بدون حرف کلی، ارجاع S#، جدا کردن داده/بنچمارک/فرضیه، سطح اطمینان، فرمت استاندارد تیتر/تامبنیل/هوک)، تاریخ امروز به مدل داده می‌شود، تحلیل دقیق چندویدیویی در پایتون (`video_set_analysis`: میانه‌ها، رتبه‌بندی، الگوی تیترهای برنده در برابر بازنده، Shorts در برابر بلند)، معیارهای مشتق برای هر ویدیو (views/day، سن، like/comment rate، نسبت به میانگین کانال)، دکمه‌های پیشنهاد ادامه گفتگو (بلاک ```next)، temperature ۰.۵۵ و سقف ۸۱۹۲ توکن با برگشت خودکار به ۴۰۹۶ برای مدل‌های قدیمی.
