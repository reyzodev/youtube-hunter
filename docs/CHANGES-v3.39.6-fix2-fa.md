# تغییرات 3.39.6-fix2

## ۱) خط رنگی کارت‌ها (گرد و داخل باکس)
`clip: true` در Qt Quick فقط مربعی برش می‌زند، برای همین خط‌های لبه از گوشه‌های گرد بیرون می‌زدند و شکل «T» داشتند.
- `AiProfileCard.qml`: خط سبز کنار کارت پرووایدر (دراپ‌داون AI) حالا یک قرص گرد، با فاصله از لبه و بالا/پایین، کامل داخل کارت است.
- `SettingsPage.qml`: نشانگر منوی کناری تنظیمات (قبلاً ‎-1px بیرون می‌زد) رفت داخل و گرد شد؛ wash پیش‌نمایش تم هم گوشه‌ی گرد گرفت.
- `CutterPage.qml`: نوار پیشرفت بالای داک برش، بین دو گوشه‌ی گرد و سرگرد.
- `Toast.qml`: خط شمارش معکوس پایین توست.
- `Teleprompter.qml`: نوار پیشرفت بالای صحنه و نوار پیشرفت هر ردیف ریل.
- `DownloadsPage.qml`: نور «busy sweep» زیر باکس لینک، داخل یک مسیر clip‌شده بین گوشه‌ها.
- `SmartField.qml`: wash فوکوس فیلدها گوشه‌ی گرد گرفت.
- `InsightsPage.qml`: پرتوی اسکن کاور با `RoundClip` به شکل گرد کاور ماسک شد.

## ۲) باگ‌ها
- **خروجی JSONL خراب بود**: Niche و Archive فرمت `"jsonl"` می‌فرستادند ولی `write_export` فقط `"json"` را می‌شناخت ← هیچ فایلی ساخته نمی‌شد و خطای FileNotFoundError می‌داد. (`core/exports.py`)
- **ذخیره‌ی اتمیک config**: `save_app_config` اول فایل را خالی می‌کرد؛ کرش/قطع برق وسط نوشتن = همه‌ی تنظیمات پاک. حالا temp + `os.replace`. (`config.py`)
- **Deno VM**: هر تیک پیشرفت دانلود ۳ بار `deno --version` را روی GUI thread اجرا می‌کرد (لگ شدید هنگام نصب). وضعیت کش می‌شود و فقط بعد از نصب/آپدیت/refresh تازه می‌شود. (`vm/deno_vm.py`)
- **اسلات‌های Settings**: `_on_ai_status`، `_on_ai_models`، `_remember_key_status` که سیگنال از thread کارگر می‌گیرند `@Slot` صریح گرفتند تا حتماً روی GUI thread اجرا شوند (تایمر ذخیره را استارت می‌کنند).
- **Quality probe**: نتیجه‌ی کندِ ویدیوی قبلی دیگر کش ویدیوی فعلی را بازنویسی نمی‌کند.
- **Downloads**: دوبار Enter سریع دیگر دو picker باز نمی‌کند.
- **کنسل تبدیل ffmpeg**: قبل از حذف فایل نیمه، صبر تا پروسه واقعاً بسته شود (در ویندوز فایل قفل بود و پاک نمی‌شد).
- **pip install yt-dlp** (فقط حالت سورس): timeout و بدون پنجره‌ی کنسول.
- **XLSX**: workbook بعد از خواندن بسته می‌شود (نشت file handle).
- **Content Lab**: favorite روی ایده‌ی پاک‌شده دیگر «موفق» گزارش نمی‌شود.
