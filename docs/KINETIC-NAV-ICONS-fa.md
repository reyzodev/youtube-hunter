# آیکون‌های متحرک منو (v7 "Kinetic")

فایل‌های تغییرکرده:
- `app/qml/components/NavIcon.qml` (جدید): ۱۲ آیکون وکتوری (QtQuick.Shapes / CurveRenderer) با انیمیشن اختصاصی هر کدام.
- `app/qml/components/NavButton.qml`: به‌جای IconGlyph از NavIcon استفاده می‌کند (برای نام‌های ناشناخته همان IconGlyph قبلی می‌ماند).

رفتار:
- با هر بار ورود ماوس فقط یک بار پخش می‌شود (لوپ نیست) و هنگام فعال شدن صفحه هم یک بار.
- اگر وسط انیمیشن ماوس خارج شود، تا آخر می‌رود و دقیقاً به حالت سکون برمی‌گردد.
- حالت فعال: خط به رنگ primary + تینت ملایم داخل بدنه آیکون (duotone).
- خاموش کردن انیمیشن: `animated: false` روی NavIcon.

تست بدون نمایشگر:
QT_QPA_PLATFORM=offscreen timeout 30 python main_qml.py
python -m PySide6.qmllint -I app/qml app/qml/components/NavIcon.qml

# رفع مشکل Fetch مدل‌ها در Custom Provider (403 Forbidden)

علت: درخواست‌ها با User-Agent پیش‌فرض پایتون (`Python-urllib/3.x`) ارسال می‌شدند که Cloudflare/فایروال اکثر روترهای AI آن را مسدود می‌کند و 403 خالی برمی‌گرداند. OpenCode هدر واقعی می‌فرستد، برای همین آنجا کار می‌کند.

تغییرات:
- `app/core/net.py`: همه‌ی درخواست‌ها (fetch و چت) User-Agent و Accept درست دارند.
- `app/core/ai/clients.py`: Fetch چند آدرس محتمل `/models` را امتحان می‌کند (نسخه در Host یا Path، اسلش آخر، `/responses`، `/messages`)، کلید را هم Bearer و هم x-api-key می‌فرستد، خروجی‌های `data/models` را می‌خواند، و خطای HTML را قابل‌فهم نشان می‌دهد. حالت Anthropic هم اول `/models` واقعی را امتحان می‌کند.
- `SettingsPage.qml`: مدل تایپ‌شده بدون Enter هم ذخیره می‌شود، و Fetch مدل انتخاب‌شده‌ی فعلی را عوض نمی‌کند.
- `app/locales/fa.py`: ترجمه‌ی پیام‌های جدید.

# رفع چشمک‌زدن (flicker) هنگام هاور — ریشه‌ای

سه علت پیدا شد:

1. **محو رنگ از "transparent" (علت اصلی چشمک).** در QML رنگ `"transparent"` یعنی «مشکیِ با آلفای صفر». ColorAnimation کانال‌ها را جدا جدا درون‌یابی می‌کند، پس محو از transparent به یک رنگ روشن (مثل hoverTint روی پنل سفید) وسط راه از یک خاکستری تیره رد می‌شود → یک فریم چشمک. این دقیقاً ردیف‌های Downloads و گزینه‌های Monetize Checker بود، و در **۴۲ جای دیگر** اپ هم وجود داشت. همه با `U.withAlpha(همان‌رنگ, 0)` جایگزین شدند تا فقط شفافیت تغییر کند.
2. **جابه‌جایی چیدمان در ردیف‌های دانلودشده.** وضعیت (تیک + زمان) و دکمه‌های هاور با `visible` جابه‌جا می‌شدند؛ عرض ستون عنوان عوض می‌شد و همه‌چیز یک لحظه می‌پرید. حالا هر دو در یک جای با عرض ثابت‌اند و فقط cross-fade می‌شوند.
3. **کارت‌هایی که روی هاور بالا می‌روند** (Downloads grid، کارت‌های درآمد Monetize، Cutter، Content Lab، Blueprint). با بالا رفتن کارت، ناحیه‌ی هاورش هم بالا می‌رفت و موس نزدیک لبه‌ی پایین مدام هاور/آن‌هاور می‌شد. کامپوننت جدید `components/LiftMask.qml` ناحیه‌ی برخورد را روی جای اصلی کارت هم نگه می‌دارد.

جلوگیری از تکرار: `python tools/check_hover_flicker.py` هر دو الگو را در کل QML پیدا می‌کند (`--fix` محوهای رنگ را خودکار درست می‌کند). قبل از هر بیلد اجرایش کن؛ الان خروجی `clean` است.
