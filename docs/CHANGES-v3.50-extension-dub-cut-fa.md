# v3.50 — افزونه: دراپ‌داون طراحی‌شده‌ی دوبله + آمار زنده‌ی برش

## ۱) انتخاب زبان صدا / دوبله (تب Download و Cut)
- `<select>` بومی حذف شد (لیست بازشده‌اش منوی سفید/آبی ویندوز بود).
- دراپ‌داون اختصاصی: چیپ کد زبان (FA / EN)، نام زبان + نام بومی، برچسب رنگی Original / Dub / Auto، تیک روی گزینه‌ی انتخاب‌شده، باز شدن با انیمیشن، و باز شدن رو به بالا وقتی پایین جا نیست.
- کیبورد: ↑/↓ ، Home/End ، Enter ، Esc (اول فقط منو را می‌بندد، نه کل پنل). کلیک بیرون منو را می‌بندد.

## ۲) کپسول برش = کپسول دانلود
- زیر کپسول برش حالا همان سه عدد دانلود هست: **سرعت** (با اسپارک‌لاین)، **حجم** («از ~X MB»)، **زمان باقی‌مانده**.
- اپ (`web_bridge.py`) حالا speed / total / eta / elapsed را در `/v1/cut/status` می‌فرستد (سرعت EMA، حجم کل با برون‌یابی از درصد).
- با اپ قدیمی هم کار می‌کند: افزونه همین اعداد را از written و pct خودش حساب می‌کند.

نسخه‌ی افزونه: 1.1.4 — در chrome://extensions روی Reload بزن.
