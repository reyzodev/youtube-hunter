# v3.49 — AI Chat: تحلیل بریف، لینک دسته‌ای، اسکوپ گفتگومحور + رفع اتصال افزونه

## AI Chat
- آیکون File از کنار Search Archive برداشته شد؛ جایش **تحلیل بریف** آمد (بریف‌های ذخیره‌شده‌ی Niche Scan یا چسباندن بریف مشتری/خودت).
- منوی + فقط «YouTube links» و «File» دارد (Search Archive، Google Drive و Image حذف شدند؛ تصویر هنوز از File یا drag & drop می‌آید).
- **لینک دسته‌ای**: تا ۵۰ لینک یک‌جا، شمارنده‌ی زنده، oEmbed موازی (۶تایی)، و با کلید API فقط ۲ واحد سهمیه برای کل دسته.
- پرامپت سیستم بازنویسی شد: قالب ثابت Verdict/Findings/Playbook حذف، لحن گفتگومحور، سلام/تشکر با گرمی جواب داده می‌شود (نه هشدار scope)، حداکثر یک سؤال در هر جواب.
- `classify_turn`: تشخیص محلی نوع پیام (سلام، سؤال سریع، تحلیل، ایده، خروجی، بریف، کاربر کلافه) بدون فراخوانی اضافه‌ی AI، تا شکل جواب با نیاز کاربر عوض شود.
- بخش «ANALYSING A BRIEF» در پرامپت: سنجش هدف، مخاطب، زاویه، شواهد، امکان‌پذیری، ریسک + نسخه‌ی تیزشده.

## سرعت
- Digest منابع روی pool محدود (۴ worker) به‌جای یک thread برای هر منبع؛ ارسال پیام وسط خواندن، منتظر همان خواندن می‌ماند (ترنسکریپت دوبار گرفته نمی‌شود).
- افزودن دسته‌ای منابع فقط یک بار لیست را از SQLite بازسازی می‌کند.
- `insights_list` با `json_extract` فقط دو فیلد را می‌خواند به‌جای parse کل JSONها.

## افزونه (Waiting for the extension)
- علت: کروم روی GET از service worker هدر Origin نمی‌فرستد، پس اپ هیچ‌وقت افزونه را «متصل» علامت نمی‌زد.
- رفع: هدر `X-YTH-Client` (افزونه 1.1.3)، تشخیص درخواست مرورگر برای افزونه‌های قدیمی، علامت‌گذاری با هر درخواست افزونه، ping هنگام بیدار شدن service worker، و دکمه‌ی «Mark as connected».
- بعد از آپدیت: در chrome://extensions روی Reload افزونه بزن.
