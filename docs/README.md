# METADATA_EXTRACTOR_X · Core Control

اسکرپر متادیتای کانال یوتیوب با ظاهر تیره‌ی «سایبری» (مطابق طرح ارسالی شما) —
منطق اصلی برنامه (گرفتن لیست ویدیوها از کانال، دریافت آمار و توضیحات، و
تلاش برای گرفتن ترنسکریپت با زبان‌های مختلف) دقیقاً همان منطق فایل پایتونی
شماست؛ فقط ظاهر و چند قابلیت جانبی جدید اضافه شده.

## نصب

```bash
pip install -r requirements.txt
```

> پوشه‌ی `fonts/` باید همیشه کنار فایل `app.py` بماند — فونت‌های
> Material Symbols، JetBrains Mono و Hanken Grotesk از همین پوشه لود
> می‌شوند تا ظاهر برنامه روی هر سیستمی یکسان بماند.

## اجرا

```bash
python app.py
```

## صفحات برنامه

- **Dashboard** — همان فرم اصلی: URL کانال، عبارت جست‌وجوی اختیاری (که
  واقعاً به‌عنوان پارامتر `q` در جست‌وجوی یوتیوب استفاده می‌شود)، تعداد
  ویدیو (اسلایدر)، مرتب‌سازی (جدیدترین / پربازدیدترین / مرتبط‌ترین)، نام
  فایل خروجی و مسیر ذخیره.
- **Logs** — نمایش زنده‌ی پیشرفت با رینگ دایره‌ای درصد و کنسول رنگی شبیه
  ترمینال؛ دکمه‌ی «EMERGENCY STOP» همان توقف اضطراری قبلی است.
- **History** — لیست فایل‌های خروجی قبلی در پوشه‌ی انتخاب‌شده (کامل /
  ناقص)، با امکان باز کردن پوشه یا حذف فایل.
- **Settings** — کلید API (با دکمه‌ی نمایش/مخفی و اعتبارسنجی واقعی روی
  یوتیوب)، فرکانس ذخیره‌ی خودکار (چک‌پوینت واقعی حین اسکرپ)، فرمت خروجی
  (CSV / JSON Lines / XLSX / SQLite — هر چهار مورد واقعاً پیاده‌سازی
  شده‌اند)، و تعداد ترد هم‌زمان (واقعاً با `ThreadPoolExecutor` برای
  سریع‌تر شدن اسکرپ استفاده می‌شود).

## نکته‌ی کلید API

به دلایل امنیتی دیگر هیچ کلیدی داخل سورس برنامه قرار ندارد. کلید
YouTube Data API خود را یک بار در صفحه‌ی Settings وارد و «Validate Key»
را بزنید؛ کلید در فایل تنظیمات شخصی شما (کنار `config.json`) ذخیره
می‌شود و دفعات بعد به‌صورت خودکار بارگذاری می‌شود.

## قابلیت‌های جدید (تم رنگی قرمز، هماهنگ با بقیه‌ی برنامه)

سه صفحه‌ی جدید به سایدبار اضافه شده که همگی از همان کامپوننت‌ها و پالت
قرمز/مشکی برنامه استفاده می‌کنند:

- **Monetize Checker** — با وارد کردن لینک/handle/نام یک کانال، اطلاعات
  پروفایل (مشترکین، بازدید کل، تعداد ویدیو، کشور، تاریخ عضویت)، یک
  تخمین از واجد شرایط بودن برای Partner Program (بر پایه‌ی آستانه‌ی
  ۱۰۰۰ مشترک — با توضیح صریح که این فقط تخمین است و وضعیت واقعی
  مانیتایز از طریق API عمومی یوتیوب قابل تأیید نیست)، و یک «ماتریس
  درآمد تخمینی» روزانه/ماهانه/سالانه بر اساس بازه‌ی CPM نمایش می‌دهد.
  دکمه‌ی «Generate AI Insight» با Gemini یک تحلیل کوتاه از نیچ، سیگنال
  رشد و پیشنهاد مانیتایز می‌سازد.

- **Idea Finder** — یک کانال را اسکن می‌کند (بر پایه‌ی uploads playlist،
  نه سرچ کوئری، تا مصرف کوتای API کمتر باشد)، برای هر ویدیو نسبت
  «آوت‌لایر» (بازدید نسبت به میانگین/میانه‌ی همان کانال) و سرعت رشد
  بازدید (ویو در ساعت) را حساب و در جدولی مرتب‌شده نمایش می‌دهد. هر
  ردیف دو دکمه دارد: «Analyze» (تحلیل هوش مصنوعی) و ذخیره در Ideas
  Board.

- **Ideas Board** — یک بورد کانبان ساده (New → Researching → Scripting
  → Ready to Film) که ایده‌های ذخیره‌شده از Idea Finder را نگه می‌دارد؛
  هر کارت با دکمه‌های ◀ ▶ بین ستون‌ها جابه‌جا می‌شود و دکمه‌ی Analyze
  همان دیالوگ تحلیل هوش مصنوعی را باز می‌کند (نتیجه هم در دیتابیس محلی
  ذخیره می‌شود).

- **Idea Analysis (دیالوگ)** — از Idea Finder یا Ideas Board باز می‌شود
  و با Gemini توضیح می‌دهد چرا آن ویدیو آوت‌لایر شده، چند ایده‌ی عنوان
  و یک هوک پیشنهادی می‌دهد.

داده‌های Idea Finder/Monetize Checker مستقیماً از YouTube Data API
(همان کلید تنظیمات) گرفته می‌شوند؛ ذخیره‌ی ایده‌ها در یک فایل SQLite
جدا (`ideas.db`) کنار فایل تنظیمات برنامه نگه‌داری می‌شود، بدون هیچ
تأثیری روی خروجی اصلی اسکرپر.

## هوش مصنوعی (Gemini)

کلید Gemini خود را در صفحه‌ی Settings → «AI Analysis (Gemini)» وارد
کنید (به دلایل امنیتی کلیدی همراه برنامه ارسال نمی‌شود)؛ در همان‌جا
می‌توانید مدل (پیش‌فرض `gemini-2.5-flash`) را هم عوض کنید. این کلید فقط برای درخواست‌های
`generateContent` استفاده می‌شود و SDK جداگانه‌ای نصب نمی‌شود (با
`urllib` استاندارد پایتون).


## به‌روزرسانی پایداری (نسخه‌ی ۲) — رفع کرش‌های تصادفی

این نسخه مشکل «کرش ناگهانی وسط اسکرپ» را از چند جهت ریشه‌یابی و رفع می‌کند:

### رفع علت‌های کرش
- **ثبت کامل خطاها در `crash.log`** (کنار `config.json`): با `faulthandler`
  حتی کرش‌های native هم ردیابی می‌شوند. اگر باز مشکلی دیدید، متن این فایل
  را بفرستید.
- **پوشش خطای تردهای کاری**: قبلاً exception داخل ترد اسکرپ می‌توانست کل
  برنامه را ساکت ببندد؛ حالا لاگ می‌شود و برنامه باز می‌ماند
  (`threading.excepthook` + دیالوگ خطا فقط از ترد رابط کاربری).
- **رفع باگ QPixmap در ترد کاری** (بارگذاری تصاویر بندانگشتی): علت
  کلاسیک segfault تصادفی در Qt.
- **بستن امن پنجره وسط اسکرپ**: با دیالوگ تأیید، توقف ورکر و جداکردن
  سیگنال‌ها — قبلاً منبع کرش هنگام خروج بود.
- **سقف رشد کنسول لاگ** (۱۵۰۰ خط): اسکرپ‌های طولانی دیگر حافظه/رندر را
  نمی‌ترکانند.
- **پاک‌سازی کاراکترهای غیرمجاز** قبل از ذخیره‌ی XLSX/CSV + نوشتن اتمیک
  فایل خروجی (دیگر فایل نیمه‌خراب نمی‌ماند).
- **Timeout سراسری ۳۰ ثانیه** برای همه‌ی اتصال‌ها + **تلاش مجدد خودکار**
  با backoff برای خطاهای گذرای شبکه/API.

### سرعت و سهمیه (Quota)
- متادیتای ویدیوها حالا **دسته‌ای (۵۰تایی در هر درخواست)** گرفته می‌شود —
  تا ۵۰ برابر درخواست کمتر.
- حالت «جدیدترین» بدون عبارت جستجو از **پلی‌لیست آپلودها** استفاده می‌کند
  (۱ واحد سهمیه به‌جای ۱۰۰ واحد per-۵۰-ویدیو) — همان چیزی که قبلاً باعث
  تمام‌شدن سهمیه وسط کار می‌شد.
- اگر سهمیه تمام شود، پیام واضح می‌گیرید و همه‌چیز ذخیره می‌شود.

### قابلیت‌های جدید
- **ادامه از چک‌پوینت (Resume)**: اگر اسکرپ متوقف/قطع شود، دفعه‌ی بعد
  برنامه می‌پرسد از همان‌جا ادامه بدهد. چک‌پوینت همیشه JSONL است.
- **ETA و سرعت زنده** در نوار پایین (تعداد/دقیقه و زمان باقی‌مانده).
- **دکمه‌های «باز کردن فایل / پوشه»** در پیام پایان کار.
- **گزینه‌ی خاموش‌کردن ترنسکریپت** در تنظیمات (فقط متادیتا؛ بسیار سریع‌تر).
- **تشخیص مسدودشدن IP** برای ترنسکریپت‌ها: بعد از چند خطای پشت‌سرهم،
  دریافت رونوشت برای همان اجرا خاموش می‌شود تا بقیه‌ی داده‌ها سالم برسند.
- **پشتیبانی کامل آدرس کانال**: `@handle`، `/channel/`، `/user/`، `/c/`،
  شناسه‌ی خام `UC…` و حتی لینک ویدیو/شورتس — با متد دقیق و کم‌هزینه.
- کد ترنسکریپت با **نسخه‌های جدید `youtube-transcript-api` (۱.x)** سازگار
  شد (کد قبلی روی نصب تازه عملاً از کار افتاده بود).
