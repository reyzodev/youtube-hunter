# تغییرات 3.41 — راهنمای جدید + تغییر تم بدون لگ

## ۱) راهنما (Tour) — ریدیزاین کامل
- **ویزوری «Lock-on»**: دور هر هدف چهار براکت قرمز (همان زبان لوگو و انیمیشن تم) با کمی overshoot قفل می‌شوند + هاله‌ی نرم که آرام نفس می‌کشد.
- **اسپات‌لایت یکپارچه**: ماسک، قاب، هاله و براکت‌ها همه از یک مستطیل انیمیت‌شده پیروی می‌کنند؛ بین هدف‌ها نرم morph می‌شود و دیگر از نقطه‌ی قدیمی پرواز نمی‌کند.
- **کارت پریمیوم**: نوار پیشرفت تکه‌تکه (یک تکه برای هر ایستگاه)، تیتر ۲۰px، متن ۱۴px خواناتر، دکمه‌ی ✕، کی‌کپ‌های ← → Esc، دکمه‌ی Next با فلشی که روی hover جلو می‌رود، و **نوک (notch)** که به هدف اشاره می‌کند.
- **کارت خوش‌آمد (Hero)**: لوگوی زنده، تیتر بزرگ، چیپ «۱۱ ایستگاه · حدود یک دقیقه»، دکمه‌ی «شروع گشت» و «فعلاً نه».
- **جای‌گذاری هوشمند**: پایین ← بالا ← کنار هدف (برای هدف‌های بلند مثل ریل ناوبری کارت کنارش می‌نشیند نه رویش).
- **حرکت**: fade-in اوورلی، سُر خوردن کارت، cross-fade + rise متن در هر گام، بستن نرم.
- RTL کامل: در فارسی ← یعنی «بعدی».
- API قبلی (`start/next/back/stop`, `hole`, `hasHole`, `index`, `count`) دست نخورده — Main.qml و هارنس تست بدون تغییر کار می‌کنند.

## ۲) لگ ریز تغییر تم (~0.3s)
- **علت**: همه‌ی حرکت‌های پرده (مدار، براکت‌ها، لوگو، iris) `NumberAnimation` روی ترد GUI بودند — همان تردی که پالت را پشت پرده عوض می‌کند. هر کلید سنگین (مثل `text` یا `border`) ترد GUI را بیشتر از بودجه‌ی ۵ms نگه می‌داشت و همه‌ی حرکت‌ها وسط راه یخ می‌زدند. iris هم یک مسیر CurveRenderer بود که هر فریم روی GUI بازسازی می‌شد.
- **رفع**: همه‌ی حرکت‌ها حالا **Animator** هستند (Opacity/Scale/Rotation/X/Y) که روی **ترد رندر** اجرا می‌شوند؛ حتی وقتی ترد GUI مشغول swap است، با فریم‌ریت کامل حرکت می‌کنند. هندسه‌ها ثابت‌اند: پرده یک Rectangle گرد، iris یک دایره‌ی ثابت که فقط scale می‌شود، کمان‌ها فقط rotate.
- iris دیگر از گوشه‌های گرد پنجره بیرون نمی‌زند.
- گیت reveal با ساعت واقعی کار می‌کند (قبلاً با شمارش tick بود و وقتی GUI گیر می‌کرد بیشتر از 900ms طول می‌کشید).
- `ThemeSwitch`: دکمه‌ی کشویی **همان لحظه‌ی کلیک** سُر می‌خورد (قبلاً وسط swap و روی ترد شلوغ حرکت می‌کرد).
- `app_controller._theme_swap_done`: ذخیره‌ی `config.json` به بعد از تمام شدن reveal (1200ms) منتقل شد، نه دقیقاً روی اولین فریم‌های iris.

# 3.41.1

## ۱) راهنما: بخشی که توضیح داده می‌شود دیگر تار/تیره نیست
- **علت**: لایه‌ی تیره با ماسک `MultiEffect` سوراخ می‌شد. روی بعضی درایورها (یا وقتی MultiEffect بی‌صدا fallback می‌کند) ماسک خالی برمی‌گشت و تیرگی روی خود هدف هم می‌افتاد.
- **رفع**: تیرگی حالا یک `Shape` واحد است: مستطیل کل پنجره + یک مستطیل گرد داخلش با `OddEvenFill`. سوراخ واقعاً هندسه است، نه ماسک؛ هیچ لایه‌ی offscreen یا shader ندارد و روی همه‌ی سیستم‌ها هدف کاملاً روشن و واضح می‌ماند.

## ۲) نوتیفیکیشن‌ها: ریدیزاین کامل («Signal Deck»)
- هدر بزرگ با زیرعنوان زنده (نقطه‌ی تپنده + «۳ مورد جدید»)، دکمه‌های تنظیمات و پاک کردن همه.
- **فیلتر کشویی**: همه / هشدارها / تکمیل‌شده، هر کدام با شمارنده.
- **گروه‌بندی**: «جدید» و «قبلی‌تر». خوانده‌شدن حالا موقع **بستن** پنل ثبت می‌شود، نه باز کردن؛ پس «جدید» واقعاً معنی دارد. نشان روی زنگ وقتی پنل باز است مخفی می‌شود.
- **کارت برای هر اعلان**: آیکون همان بخشی که اعلان از آن آمده (همان آیکون منوی کناری) با یک نشان کوچک نوع (موفق/خطا/هشدار)، عنوان + زمان، پیام تا ۳ خط، مسیر فایل به صورت چیپ مونو، و «باز کردن ←» برای اعلان‌هایی که به صفحه‌ای وصل‌اند.
- hover: کارت روشن می‌شود و ✕ ظاهر می‌شود؛ حذف با انیمیشن سُر خوردن.
- باز شدن پنل با scale + fade، ردیف‌ها پله‌ای وارد می‌شوند.
- حالت خالی پریمیوم: حلقه‌های متحدالمرکز آرام و توضیح کوتاه.
- پس‌زمینه `GlassPanel` (سایه‌ی 9-slice) به جای MultiEffect؛ روی سیستم بی‌GPU هم درست دیده می‌شود.
- فوتر «تنظیمات اعلان» → صفحه‌ی تنظیمات.

فایل‌ها: `TourOverlay.qml`، `NotificationsTray.qml`، `TitleBar.qml`، `locales/fa.py`.
