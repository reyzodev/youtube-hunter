# انتخاب ترک صدا (دوبله) — کاتر + دانلودر

ویدیوهای دوبله‌شدهٔ یوتیوب برای هر زبان یک ترک صدا دارند (اصلی + دوبلهٔ سازنده + دوبلهٔ خودکار هوش مصنوعی یوتیوب).
حالا کاربر خودش انتخاب می‌کند کدام صدا در کلیپ / فایل دانلودی باشد. پیش‌فرض همیشه **اصلی** است.
برای ویدیوهای تک‌زبانه هیچ چیزی نمایش داده نمی‌شود.

## UI — «Voice Deck» (`app/qml/components/AudioTrackPicker.qml`، کامپوننت مشترک)
- هر زبان یک کارت: کاشی کد زبان (EN / AR / ES)، نام به خط خود زبان (العربية، Español)، نام فارسی/انگلیسی + بیت‌ریت.
- نشان نوع: **اصلی** (سبز)، **دوبله** (رنگ اصلی تم)، **دوبلهٔ هوش مصنوعی** (رنگ tertiary + tooltip).
- کارت انتخاب‌شده: حاشیهٔ رنگی، نور ملایم از لبهٔ خواندن، کاشی پر، و یک **voice meter چهارمیله‌ای که نفس می‌کشد**
  (فقط وقتی Ambient motion روشن و پنجره فعال است).
- لیست‌های بلند (دوبلهٔ خودکار گاهی ۲۰+ زبان) جمع می‌شوند + دکمهٔ «نمایش همه»؛ گزینهٔ انتخاب‌شده همیشه دیده می‌شود.
- RTL / فارسی کامل، تم لایت و دارک.

## Video Cutter
- کارت جدید «ترک صدا» زیر «Quality & output» (فقط برای لینک‌های دوبله‌دار).
- **پیش‌نمایش همان لحظه به صدای انتخاب‌شده عوض می‌شود** (حتی وسط پخش).
- کات با همان زبان انجام می‌شود: مسیر سریع ffmpeg، fallbackها، مسیر yt-dlp و retry «Refreshing streams…».
  وقتی دوبله انتخاب شده، فایل‌های progressive کنار گذاشته می‌شوند (فقط صدای پیش‌فرض دارند).
- نام فایل: `... [ar].mp4` و برچسب کلیپ در تاریخچه: `1080p · AR`.

## دانلودر (Niche Finder، Search Archive، Downloads)
- بخش «ترک صدا» در پنجرهٔ انتخاب کیفیت، زیر فرمت ویدیو.
- حجم‌های نمایش‌داده‌شده هم با ترک انتخاب‌شده دوباره حساب می‌شوند.
- انتخاب در کلید کیفیت ذخیره می‌شود (`1080p@mp4~ar`) پس **Resume** بعد از ری‌استارت هم همان زبان را می‌گیرد.
- فایل دوبله کنار نسخهٔ اصلی ذخیره می‌شود (`... 1080p ar.mp4`)، رویش نمی‌نویسد. برچسب ردیف: `1080p · MP4 · دوبله: Arabic`.
- اگر یوتیوب آن دوبله را دیگر ندهد، دانلود شکست نمی‌خورد و صدای اصلی می‌گیرد.
