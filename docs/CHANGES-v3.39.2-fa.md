# تغییرات نسخه 3.39.2

## Search Archive: لودینگ کامل کارت‌ها
وقتی یک keyword یا channel در Search Archive باز می‌شود، کارت‌های واقعی تا آماده شدن تمام thumbnailهای صفحه نمایش داده نمی‌شوند. به‌جای ورود تدریجی متن و عکس، یک گرید skeleton با همان اندازه و چیدمان کارت‌ها نمایش داده می‌شود و یک موج نور مورب روی آن حرکت می‌کند؛ بعد از آماده شدن همه thumbnailها، skeleton محو شده و کارت‌ها با هم ظاهر می‌شوند.

اگر thumbnail خراب یا بدون تصویر باشد، همان مورد هم به‌عنوان settled حساب می‌شود تا صفحه بی‌دلیل روی loading نماند.
