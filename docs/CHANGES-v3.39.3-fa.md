# تغییرات نسخه 3.39.3

## بهینه‌سازی لودینگ Search Archive

لودینگ Archive از دو گرید جدا به یک گرید واحد تبدیل شد. قبلاً گرید skeleton و گرید کارت‌های واقعی همزمان ساخته می‌شدند که برای لیست‌های بزرگ، layout و آبجکت‌های اضافه تولید می‌کرد.

حالا هر سلول فقط یک کارت واقعی دارد و skeleton به‌صورت overlay روی همان سلول نمایش داده می‌شود. ابعاد و ستون‌ها دقیقاً از همان grid اصلی می‌آیند، موقع آماده شدن همه thumbnailها skeleton محو می‌شود و کارت واقعی ظاهر می‌شود.
