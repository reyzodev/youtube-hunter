# v3.46: Cut follows you, with audio and output formats

- Chrome Cut jobs now heartbeat through the bridge while the panel is open. When the user navigates away, the same desktop live activity card appears and follows the cut until completion, just like downloads.
- Chrome Cut now offers MP4, MKV, WEBM, MP3, M4A, OPUS, WAV, and FLAC. MP3/M4A/OPUS/WAV/FLAC cut the selected audio track without video. Video cuts retain audio.
- The desktop Cutter page now exposes the same output-format row and audio-only choices, and passes dubbed-track selections through to the cutter.
- Local-file cuts accept the selected output format and audio-only mode as well.
