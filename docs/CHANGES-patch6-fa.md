# v3.18 — patch 6 (Keyword Lab · دو موتور: یوتیوب × گوگل)

## از KeywordPro اضافه شد (همه رایگان، بدون درخواست پولی)
- **Who ranks today** → «چه کسی الان در یوتیوب رتبه دارد»: ۶ ویدیوی برتر کلمهٔ انتخاب‌شده با تامبنیل، بازدید، سن و ضریب نسبت به میانه (کلیک = باز شدن در یوتیوب).
- **Difficulty spread** → هیستوگرام ۵ سطحی سختی (KD).
- **Cross-engine volume** → تب کامل «یوتیوب در برابر گوگل»: سهم میانگین، سهم هر کلمه، همپوشانی تکمیل خودکار (فقط یوتیوب / هر دو / فقط گوگل)، Rising و Related جداگانه برای هر موتور، مناطق هر موتور.
- **Keyword table** → کاوشگر کامل: فیلتر، جست‌وجو، مرتب‌سازی، ستاره، اسپارک‌لاین روند، ستون گوگل، نوار سهم موتور.
- **People also ask / Related** → تب ایده‌ها: سؤال‌ها، زیرموضوع‌ها، پک تگ ۵۰۰ کاراکتری، همهٔ عبارت‌ها، ترند لحظه‌ای.
- **Saved sessions** → تب ذخیره‌شده‌ها + اجراهای اخیر.
- **JSON export** → `exportReport` (کل گزارش)، کنار CSV/Excel.

## داده‌های جدید گوگل (core/keywords/research.py)
- `web_vocabulary`: تکمیل خودکار گوگل (فقط کلمات سؤالی، ~۱۲ درخواست سبک).
- `web_regions`, `web_related`: از همان دستهٔ Trends وب که قبلاً اجرا می‌شد (صفر درخواست اضافه).
