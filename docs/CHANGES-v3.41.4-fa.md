# تغییرات v3.41.4 — دستیار PO Token (bgutil-pot)

## این چیست؟
یوتیوب از کلاینت‌های خانواده‌ی WEB (web، web_safari، mweb، tv_simply…) یک «PO Token» می‌خواهد: اثباتی که BotGuard گوگل برای هر ویدیو جداگانه می‌سازد و نشان می‌دهد درخواست از یک مرورگر واقعی آمده. بدون آن، لینک استریم این کلاینت‌ها 403 می‌دهد یا فقط لیست «لاغر» (360p) برمی‌گردد. این مشکل بیشتر روی IPهای پرچم‌خورده دیده می‌شود: VPN، دیتاسنتر، NAT مشترک.
`bgutil-pot` همان BotGuard را داخل یک V8 جاسازی‌شده اجرا می‌کند و برای هر ویدیو توکن تازه به yt-dlp می‌دهد.

## چه کاری را حل نمی‌کند
- کلاینت‌های tv، android_vr و web_embedded اصلاً توکن لازم ندارند.
- توکن android/ios با DroidGuard/iOSGuard ساخته می‌شود و این ابزار نمی‌تواند آن را بسازد.
- جای کوکی را برای بلاک واقعی «Sign in to confirm you're not a bot» نمی‌گیرد؛ فقط ترافیک را «معتبرتر» نشان می‌دهد.

## چرا نسخه‌ی Rust و نه Node
| | Rust (jim60105) | Node/TS (Brainicism) |
|---|---|---|
| نصب | یک exe تنها (~۴۴ MB) | Node ≥ 22 یا deno + git clone + `npm ci` (وابستگی native به canvas) + `tsc` |
| مناسب کاربر نهایی | بله | نه |
| API | همان HTTP API (`/get_pot`، `/ping`) | مرجع اصلی |
| امنیت | پیش‌فرض روی `[::]` گوش می‌دهد ← ما همیشه `--host 127.0.0.1` و پورت تصادفی می‌دهیم | در 2.0.0 یک RCE (GHSA-qpv9-8xfj-xx9m) رفع شد |

## پیاده‌سازی
- `app/core/pot.py`: پیدا کردن exe (assets/bin ← پوشه‌ی managed کنار config ← PATH)، اجرای تنبل سرور روی 127.0.0.1 با پورت آزاد تصادفی، Job Object در ویندوز (با بسته‌شدن یا کرش برنامه، سرور هم بسته می‌شود)، و یک PoTokenProvider کوچک روی چارچوب رسمی yt-dlp (2025.05.22+). **فایل پلاگین شخص ثالث لازم نیست.**
- ثبت provider در `js_runtime_opts()` انجام می‌شود (قبل از ساخت هر YoutubeDL)، پس بعد از «Update downloader» و reload هم دوباره ثبت می‌شود.
- warm-up شروع برنامه، اگر helper نصب باشد سرور را بالا می‌آورد تا اولین ویدیو منتظر نماند.
- هر خطا = «توکن نداریم» و yt-dlp مثل قبل ادامه می‌دهد. اگر سرور بالا نیاید، تا ۲ دقیقه دوباره امتحان نمی‌شود.
- نصب از تنظیمات ← Download Engine ← «PO TOKEN HELPER»: دانلود نسخه‌ی v0.8.1 از GitHub Releases با **SHA-256 پین‌شده**، تست با `--version` و بعد جایگزینی. سوییچ روشن/خاموش (`pot_helper` در config).

## باندل کردن در نصب‌کننده (اختیاری)
فایل `bgutil-pot-windows-x86_64.exe` را با نام `assets\bin\bgutil-pot.exe` بگذارید. spec کل `assets` را باندل می‌کند، پس کار دیگری لازم نیست. مجوز GPL-3.0 است: کنار برنامه به‌عنوان برنامه‌ی جدا قابل توزیع است، ولی متن مجوز و لینک سورس را همراهش بگذارید.
