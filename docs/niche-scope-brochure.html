نیچ اسکوپ یک ابزار تک‌کاره نیست؛ یک میز کار است. ده اتاق دارد و هر اتاق یک قدم از یک کار واقعی را برمی‌دارد: از خالی‌بودن صفحه تا فایل آماده‌ی آپلود. کاری که بین این اتاق‌ها می‌گذرد روی همان دستگاه شما ذخیره می‌شود — نه روی سرور کسی. Niche Scope is not a single-purpose tool; it is a desk. Ten rooms, each taking one step of real work: from an empty page to a file ready to upload. Everything that passes between those rooms is saved on your own machine — not on someone's server.

تفاوت اصلی‌اش با ابزارهای مشابه این است که سهمیه‌ی API یوتیوب را مثل بودجه خرج می‌کند و همیشه به شما نشان می‌دهد چقدر مانده. هر جست‌وجویی که یک بار انجام دهید، برای همیشه در آرشیو می‌ماند و باز کردنش دیگر هیچ هزینه‌ای ندارد. What sets it apart is that it treats the YouTube API quota as a budget and always shows you what is left. Every search you run once is archived forever, and reopening it costs nothing.

اسکرپرScraper

نیچ فایندرNiche Finder

چه کاری نمی‌کندWhat it will not do

  • عدد از خودش نمی‌سازد. همه‌ی آمار از YouTube Data API می‌آید و همه‌ی محاسبه‌ها روی همان داده انجام می‌شود. It does not invent numbers. Every statistic comes from the YouTube Data API, and every calculation is done on that same data.
  • وضعیت مانیتایز را تأیید نمی‌کند. این عدد از API عمومی یوتیوب در دسترس نیست؛ آنچه می‌بینید یک تخمین است و برنامه همین را می‌نویسد. It does not confirm monetization status. That is not available from YouTube's public API; what you see is an estimate, and the app says so.
  • جای یوتیوب استودیو را نمی‌گیرد. نرخ کلیک و زمان تماشا فقط برای کانال خودتان و فقط داخل استودیو دیده می‌شود. هر ادعایی که به این داده نیاز دارد، برچسب «نیازمند استودیو» می‌خورد. It is not a replacement for YouTube Studio. Click-through rate and watch time exist only for your own channel, inside Studio. Any claim that needs them is labelled “needs Studio”.
  • سهمیه‌ی یوتیوب را دور نمی‌زند. ۱۰٬۰۰۰ واحد در روز سقف گوگل است. کاری که برنامه می‌کند این است که ارزان‌ترین راه را انتخاب کند و مصرف را جلوی چشم شما بگذارد. It does not get around the YouTube quota. 10,000 units a day is Google's ceiling. What the app does is take the cheapest route and keep the spend in front of you.
  • کلید API همراهش نمی‌آید. کلید یوتیوب و کلید هوش مصنوعی را خودتان یک بار در تنظیمات وارد می‌کنید و روی همان دستگاه می‌ماند. It does not ship with API keys. You enter your YouTube key and your AI key once in Settings, and they stay on that machine.

Paste your YouTube Data API key in Settings, pick an AI provider, and run one keyword. The first-run tour walks you from there to your first blueprint.
