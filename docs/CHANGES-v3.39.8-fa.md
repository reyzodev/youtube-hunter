# تغییرات 3.39.8 — سرعت و روانی

## ۱) لگ تغییر تم بعد از چند دقیقه کار
- علت اصلی: صفحه‌هایی که یک بار باز شده‌اند زنده می‌مانند؛ با هر تغییر تم آیکون‌های **همه‌ی** صفحه‌ها دوباره از Python درخواست می‌شدند و باقی‌مانده‌ی swap در یک فریم flush می‌شد (~0.4s).
- `IconGlyph`: آیکون صفحه‌ی مخفی دیگر reload نمی‌شود؛ وقتی دیده شد به‌روز می‌شود.
- `svg_icon_provider`: هر SVG فقط یک بار parse/rasterize می‌شود (mask) و رنگ با SourceIn اعمال می‌شود (۲۰ تا ۵۰ برابر ارزان‌تر).
- `ThemeWipe`: iris صبر می‌کند تا swap مرحله‌ای تمام شود (حداکثر 900ms) به‌جای flush یکجا. اسلات جدید `App.themeSwapPending()`.

## ۲) لگ‌های گاه‌به‌گاه بین تب‌ها
- event filter دو helper نشانگر موس (`cursor_guard`, `premium_cursor`) از سطح application به سطح window منتقل شد؛ قبلاً هر event برنامه (تایمر، سیگنال، انیمیشن) از Python رد می‌شد.
- `gc_pacing.py` جدید: freeze هیپ بعد از استارت، توقف GC حین انیمیشن تم/تب، collect کامل وقتی پنجره از فوکوس خارج می‌شود.
- اولین بازدید هر صفحه async ساخته می‌شود (کلیک فریز نمی‌کند)؛ در تور همان حالت sync قبلی.

## ۳) Insights
- دونات «How long they are» رنگ‌های متمایز گرفت (صورتی/کهربایی/فیروزه‌ای/آبی/بنفش) به‌جای سایه‌های نزدیک رنگ اصلی.

## ۴) ریدیزاین «شکل مجموعه» در Snapshot Insights
- **How long they are**: دونات حذف شد. به‌جایش عدد میانه‌ی بزرگ، خط «رایج‌ترین طول»، نوار طیفی چندتکه و جدول ۵ بازه (همه‌ی بازه‌ها حتی خالی‌ها، هر کدام با رنگ جدا + تعداد + درصد). hover روی نوار و ردیف هم‌زمان روشن می‌شود.
- **How fresh they are**: تایم‌لاین ۴ ستونه از جدید به قدیم (بازه‌های خالی هم دیده می‌شوند)، درصد ۳۰ روز اخیر در هدر، «منتشرشده در این هفته».
- **Who holds this niche**: حکم تمرکز (یک کانال مسلط / چند کانال جلودار / میدان باز)، عدد بزرگ سهم کانال اول، سه کارت کوچک (تعداد کانال، سهم ۳ تای اول، بقیه)، فهرست رتبه‌دار با مونوگرام رنگی و نوار سهم، بخش «بقیه» خاکستری روی نوار.
- VM: `durationSpectrum`, `recencyTimeline`, `datedRows`, `totalVideos`, `channelCount` (قبلی‌ها دست نخورده‌اند).
- `Utils.js`: `catHue()` و `ageHue()` — پالت جدا برای تم تیره و روشن.
- رشته‌های فارسی جدید در انتهای `locales/fa.py`.
